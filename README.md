# Sumitt_Central_Station_Server
Central Station Sever for Alarm Monitoring Companys for Linux  in C++ with PHP front end

This will be a central station server for Alarm Companys written for the Linux Operating System it will be comprised of a TCP/IP server that will follow and extend the Ademco and Contact ID Protocol. It will have a PHP GUI for monitoring the alarms in real time and to manage the back-end database. The Back-end database will be MONGO DB for flexibility at the cost of size.
